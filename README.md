# pyspark-movie-reviews

Assignment 1.3 for Data and Storytelling Course

## About this project
This project processes an IMDb Movie Review dataset consisting of ~50k movie reviews and their overall sentiments. 

These following steps are performed:
- Use PySpark to load CSV dataset as DataFrame.
- Display the first 5 rows.
- Clean the dataset by removing null or empty rows.
- Count total number of reviews, total number of positive reviews and total number of negative reviews.
- Create a new column to store length of each review.
- Display only those rows with review length greater than 500 characters.
- Save the transformed DataFrame as a new CSV file.

## Resources used
Movie Review Dataset: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews
